# Panther model

`panther-source.urdf` and `assets/` are generated by `scripts/prepare-panther-model.py` from
`assets/panther_urdf/panther/src/panther_description/description/panther/` in the
workspace. The original URDF and meshes remain the source of truth. The script
changes ROS `package://` mesh URLs to browser-relative URLs and fixes one
`originv` typo. The separate `panther.urdf` and `meshes/` already present in this
directory are left untouched. Do not edit the generated source model by hand.
